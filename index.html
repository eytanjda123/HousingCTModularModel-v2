Biggest levers
    Inter-city comparison

    Same building, three cities

    Each bar is what the building must sell for to cover cost and margin (required proceeds), and who pays for it. The buyer pays what income and the appraisal allow. Illustrative subsidies fill the rest in order, and red is what is still unfunded. Triangles mark the baseline.

    Funding stack: what the program documents say

    We only build in a stacking rule when a program document states it. Everything else is marked for legal review. Unchecking a source takes it out of every city's stack, so you can test a "what if this doesn't come through" case. It is not a finding that the source is unavailable.

    Portfolio

    A 10-building order across the three cities

    The modular cost in the workbook assumes a 10-building order. Split those buildings across the cities to see program-level totals, and check them against the caps the program documents state. The 4 / 3 / 3 starting split is only an example.

    Sensitivity sweep

    Move one input across its range

    The sweep follows the last slider you touched and runs across that input's researched range. Every other input stays at its current setting. A city-only input is set to the same value in all three cities, so the lines stay comparable. Dots mark each city's current value.

    What moves the remaining gap

    One change at a time, from current settings

    These are the scenarios from section 10 of each city tab. Each bar shows how much the remaining gap after the illustrative stack changes. Bars to the left, in green, mean a smaller gap.

    Research slots

    Inputs not yet in the workbook

    These are off by default, so the numbers match the workbook until you turn one on. Each one feeds into the math where we expect it would. The starting values are rough guesses for testing, not findings.
